# ASIM v0.3.0 实施计划

依据：`docs/superpowers/specs/2026-11-22-asim-v0.3.0-design.md`

## Task 1 — relay 节点层

- 新增 `router/asim-relay/node.go`：
  - `Node` 结构扩展；`proto()`/`skipVerify()`/`validate()`；
  - `udpSession` 接口；trojan 会话重构；
  - 内嵌 Xray 引擎（`infra/conf` + `core`，子集 import，避免 wireguard/gvisor 冲突）+ SOCKS5 UDP 客户端；
  - Hysteria2 引擎与会话；
  - `dialSession(node, dst)`；`probe(node)` 做真实 UDP 往返测延迟。
- `go.mod` 增加 `xray-core v1.251208.0`、`hysteria/core/v2 v2.14.0`，pin gvisor。

验证：`go build ./...`，`go vet ./...`。

## Task 2 — relay API 与热更新

- `main.go`：`/config` GET/PUT、`/ping` POST；`/status` 增 `protocol`/`version`；
- 配置写保护（`cfgMu`）、节点变更时关闭旧引擎并清理 flow、域名变更立即重解析；
- 监听地址变更只落盘并返回 `restart_required`。

验证：本机启动，curl 走通 GET/PUT/ping。

## Task 3 — relay 测试

- `node_test.go`：校验表、Xray JSON 映射、`skipVerify` 默认值、假 SOCKS5 服务端往返、假 trojan TLS 服务端往返。
- 本机对真实 VLESS 节点跑 `/ping`（需网络）。

验证：`go test ./...` 全绿；`/ping` 返回毫秒数。

## Task 4 — 模块脚本

- `asimd.sh`：默认网关探测、`router_url()`、`setrouter`、state.json 增加 `router_api`/`gateway`、selftest 增用例。
- `config/asim.conf`：`ROUTER_API=""`（留空=自动网关）并更新注释。

验证：手机 adb 上跑 `asimd.sh selftest`。

## Task 5 — WebUI

- 路由器地址卡片（默认网关、保存）；
- 节点配置卡片（协议/地址/端口/密码/SNI/insecure + 高级项），读取 `/config`、保存 `/config`；
- 延迟测试；状态区显示协议/运行时间/丢包。
- JSON 用 base64 传临时文件，避免引号注入。

验证：本地 mock `ksu` 浏览器目检 + 手机实际打开。

## Task 6 — 文档、版本、构建

- `module.prop` → v0.3.0；`README.md`、`router/asim-relay/README.md`；
- `build.ps1` 同时构建 linux/windows amd64 relay；`.gitignore` 忽略 windows 产物。

验证：`.\build.ps1` 产出 zip + 两个二进制。

## Task 7 — 部署与端到端验证

- 部署新 relay 到 192.168.100.1，保留 `relay.json` 的生产 trojan 配置并补 `protocol`/`insecure`；
- `/status`、`/config`、`/ping`；向 500 端口发 IKE 包确认 flow 建立；
- 手机 selftest；WebUI 实际打开。

## Task 8 — 提交、推送、Release

- `git add`、提交、push；
- `gh release create v0.3.0` 附 zip + 两个二进制（需 `gh auth login`）。
