# ASIM 实施计划（v2，M0-B 后重构）

> **For agentic workers:** 逐任务执行，checkbox 追踪。

**Goal:** 手机 KSU 模块负责「勾选的 SIM 卡永不驻网 + 状态面板」；VoWiFi 分流放在家庭 OpenWrt 上（ePDG 域名/IP 走英国节点）。系统 WFC 栈完全不动。

**Architecture:** 基带自己做 IKE/IPsec 且不经过手机 IP 栈（M0-B 已实测），因此手机侧不做任何流量分流。路由器侧 mihomo 用 fake-ip + 域名规则把 ePDG 流量送英国节点；手机侧模块只操作 `set-allowed-network-types-for-users` / 手动选网。

**Tech Stack:** KernelSU 模块规范、toybox shell、KSU WebUI（单文件 html + ksu exec）、OpenWrt 上的 mihomo（现有订阅）。

**Spec:** `docs/superpowers/specs/2026-11-22-asim-design.md`

## Global Constraints

- 持久状态存 `/data/adb/asim/`（`state.json`、`slot<id>.mask`）。
- 禁止使用 `disable-physical-subscription`（断电 UICC → AKA 不可用）。
- 每个改网络类型的操作都必须可逆，且原值先落盘再改；`stop`/`uninstall` 强制恢复。
- 设备：小米 12S Pro（Android 17，KSU 3.4.2），adb 序列号 `994e779c`；目标卡 subId=1（CTExcel 234/33），受保护卡 subId=2（联通）。
- 真机验证：步骤里写命令与期望输出。
- 基带 IWLAN 状态卡死时**只能整机断电**（AP 重启无效，`restart-modem` 无权限，remoteproc 被 SELinux 拦）。

### Task 3: M0-C — 路由器侧 ePDG 分流验证（唯一剩余 go/no-go）

**Files:**
- Create: `router/mihomo-asim.yaml`（只含 ASIM 需要的片段，用户合并进自己的配置）
- Create: `m0/M0-C-RESULT.md`

**Interfaces:**
- Produces: 可用的路由器配置片段 + 结论（家庭 WiFi 下 WFC 是否注册成功）。

- [ ] **Step 1:** 写 `router/mihomo-asim.yaml` 片段：`dns.enable: true`、`enhanced-mode: fake-ip`、`fake-ip-filter` 保持默认、`dns-hijack: [any:53]`；`tun` 或 `tproxy` 入站；`rules` 只加两条：`DOMAIN-SUFFIX,3gppnetwork.org,UK01`、`IP-CIDR,31.94.76.0/24,UK01`；`proxies` 里 UK01 = 订阅英国节点（`udp: true`）。其余 `MATCH,DIRECT`。
- [ ] **Step 2:** 用户把片段并入 OpenWrt 上的 mihomo（或 sing-box 等价配置），确保手机 WiFi 的 DNS 是路由器。
- [ ] **Step 3:** **整机断电重启手机**（清基带 IWLAN 状态），开机后连家庭 WiFi，不手动切任何开关。
- [ ] **Step 4:** 断言（adb）：
  - `adb shell "dumpsys telephony.registry | grep 'notifyDataConnectionForSubscriber: phoneId=1' | tail -2"` → 出现 `CONNECTED, transport: WLAN, network type: IWLAN`
  - `adb shell "ip -br addr show rmnet_data1"` → 有 ePDG 分配的地址
  - `adb shell "logcat -d -b all | grep 'DNC-1' | tail -1"` → `WLAN: IWLAN, HOME`
  - 手机发一条短信到 CTExcel 号码，另一台设备能收到。
- [ ] **Step 5:** 联通卡无感：手机关飞行模式（若开着则关掉）、确认 subId=2 蜂窝上网正常；`adb shell "curl -s ipinfo.io/country"` 期望 `CN`。
- [ ] **Step 6:** 写 `m0/M0-C-RESULT.md`；失败则记录 DNS/规则/TUN 哪一层并给出下一步；Commit。

### Task 4: M0-D — 防驻网三方案实测（go/no-go 第二半）

**Files:**
- Create: `m0/M0-D-RESULT.md`

**Interfaces:**
- Consumes: Task 3 的可用 WFC 环境。
- Produces: 默认模式（A/B/C）与每种的副作用记录，供 Task 5 使用。

- [ ] **Step 1:** 记录基线：`adb shell "cmd phone get-allowed-network-types-for-users -s 1"`。
- [ ] **Step 2:** 逐个测试（每次测完恢复）：
  - **A（GSM-only）**：设 GSM bitmask（`NETWORK_MODE_GSM_ONLY`），等 60s，断言 voice/data 不 `IN_SERVICE`，且 WFC 仍 `IWLAN HOME`（SIM 上电、AKA 可用）。
  - **B（bitmask 0）**：设 0，看命令是否被接受；被接受则同上断言。
  - **C（手动选网）**：进设置手动选一个不可用的外国网络 → 选网失败 → 断言同上；恢复为自动。
- [ ] **Step 3:** 每种模式额外记录：`adb shell "dumpsys telephony.registry | grep -o 'mVoiceRegState=[0-9]*([A-Z_]*)'"`、`ip -br addr show rmnet_data0`、以及是否能上网（应不能）。
- [ ] **Step 4:** 写 `m0/M0-D-RESULT.md`，给出默认模式；Commit。

### Task 5: `nocamp.sh` 与恢复保证

**Files:**
- Create: `module/scripts/nocamp.sh`
- Test: `sh nocamp.sh selftest`（打印将要执行的命令，不执行）

**Interfaces:**
- Produces: `nocamp.sh lock <slotId> <gsm|zero|manualplmn>`、`nocamp.sh unlock <slotId>`、`nocamp.sh status`。原值存 `/data/adb/asim/slot<slotId>.mask`。

- [ ] **Step 1:** 写 `lock`：读原值 → 落盘（chmod 600）→ 设无网值 → 回读校验；失败必须回滚。
- [ ] **Step 2:** 写 `unlock`：读存档 → 恢复 → 回读校验 → 删档（无档则不动）。`manualplmn` 模式额外把网络选择恢复为自动。
- [ ] **Step 3:** 写 `selftest`：断言命令拼装正确（含 subId 映射），不触碰真机。
- [ ] **Step 4:** 真机：lock → 断言不驻网且 WFC 正常；unlock → 断言 mask 恢复原值、卡能驻网。
- [ ] **Step 5:** Commit。

### Task 6: `asimd.sh` 状态守护与 `service.sh`

**Files:**
- Create: `module/scripts/asimd.sh`、`module/service.sh`、`module/uninstall.sh`、`module/config/asim.conf`

**Interfaces:**
- Consumes: `nocamp.sh`。
- Produces: `asimd.sh start|stop`；每 120s 校验勾选槽的 mask 仍是无网值（系统重启/更新后重施），并把状态写 `/data/adb/asim/state.json`（各卡 reg 状态、IMS 注册状态、当前 mask、模式、时间戳）。

- [ ] **Step 1:** 写 `asimd.sh`：读 `asim.conf`（勾选槽 + 模式）→ lock → 循环校验（若 mask 被外部改回则重施）→ 写 state.json。
- [ ] **Step 2:** 写 `service.sh`：等 `sys.boot_completed` → 首次安装生成 `asim.conf` → `asimd.sh start`。
- [ ] **Step 3:** 写 `uninstall.sh`：`asimd.sh stop` + 对每个存在存档的槽 `nocamp.sh unlock`。
- [ ] **Step 4:** 打包安装：`build.sh` → `adb push` → `adb shell su -c "ksud module install ..."`；重启，断言 mask 已施加、WFC 5 分钟内注册。
- [ ] **Step 5:** 手动 `asimd.sh stop` 与模拟 uninstall，断言全部恢复；Commit。
