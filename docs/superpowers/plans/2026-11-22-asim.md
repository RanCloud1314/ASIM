# ASIM 实施计划（v3，M0-C / M0-D 实测后）

> **For agentic workers:** 逐任务执行，checkbox 追踪。先读 `docs/HANDOFF.md`。

**Goal:** 手机 KSU 模块负责「勾选的 SIM 卡永不驻网 + 状态面板 + 路由器中继开关」；VoWiFi 分流已在家庭 OpenWrt 上用 Go 中继实现并验证。

**Architecture:** 基带自己做 IKE/IPsec 且不经过手机 IP 栈（M0-B 已实测），因此手机侧不做任何流量分流。路由器 `asim-relay` 把 ePDG 的 UDP 500/4500 经英国 trojan 转出去；手机侧模块只操作 `set-allowed-network-types-for-users`（GSM-only）。

**Tech Stack:** KernelSU 模块规范、toybox shell（**无 awk**，有 sed / grep / curl / flock / timeout）、KSU WebUI（单文件 html + `ksu.exec`）、Go（路由器侧已完成）。

**Spec:** `docs/superpowers/specs/2026-11-22-asim-design.md`

## Global Constraints

- 持久状态存 `/data/adb/asim/`：`asim.conf`、`slot<slot>.mask`（原值十进制）、`state.json`、`asimd.pid`。
- **`-s` 是 slot id，从 0 开始**：slot 1 = CTExcel（目标），slot 0 = 联通（禁止触碰）。**订阅号要用 `dumpsys isub` 现解析，不许硬编码。**
- 网络类型参数是**二进制字符串**（`Long.parseLong(s, 2)`）；原值存十进制，写入时现转。
- GSM-only = `1000000000000000`（= 十进制 32768）；本机原值 = `840583` = `11001101001110000111`。
- 禁止 `disable-physical-subscription`；禁止改动 slot 0 的任何网络设置。
- 每个改网络类型的操作都必须可逆：**原值先落盘再改**，改完回读校验，失败必须回滚。
- 模块脚本以 `u:r:ksu:s0`（root）运行，实测可正常调用 `cmd phone`。
- 真机验证：步骤里写命令与期望输出。设备 adb 序列号 `994e779c`。
- 基带 IWLAN 状态卡死时**只能整机断电**（AP 重启无效，`restart-modem` 无权限，remoteproc 被 SELinux 拦）。

### Task 5: `nocamp.sh` — 防驻网与恢复保证

**Files:**
- Create: `module/scripts/nocamp.sh`

**Interfaces:**
- Produces:
  - `nocamp.sh lock <slot>` — 存档原值后设为 GSM-only，回读校验
  - `nocamp.sh unlock <slot>` — 从存档恢复，回读校验
  - `nocamp.sh status [slot]` — 人读输出（当前 subId / 运营商 / mask / reg 状态）
  - `nocamp.sh selftest` — 只打印将要执行的动作，不碰真机
- 存档：`/data/adb/asim/slot<slot>.mask`（十进制原值，chmod 600）
- 内部函数后续任务复用：`slot_mask`、`dec2bin`、`apply_mask`、`verify_mask`

- [x] **Step 1:** 写 `slot_mask <slot>`：从 `dumpsys isub` 取该槽 `allowedNetworkTypesForReasons=user=<n>` 的十进制。
  - 设备上**没有 awk**，用 `grep -o` + `sed`。
  - 形如：`dumpsys isub | grep -F "simSlotIndex=$slot " | grep -o 'allowedNetworkTypesForReasons=[^ ]*' | head -1 | sed 's/.*user=//; s/,.*//'`
  - 解析为空必须中止（不能拿空值当 0 存盘）。
- [x] **Step 2:** 写 `dec2bin`（posix shell，`$((n/2))` 循环）。自测：`dec2bin 840583` → `11001101001110000111`，`dec2bin 32768` → `1000000000000000`。
- [x] **Step 3:** 写 `lock`：已锁则直接返回 0（幂等）；否则 原值落盘 → `set ... -s <slot> 1000000000000000` → 校验 `get` 输出含 `GSM` 且 `slot_mask` == 32768；任一失败则用存档回滚并删档返回非 0。
- [x] **Step 4:** 写 `unlock`：无存档则返回 0（幂等）；否则 `dec2bin 存档` → 写入 → 校验 `slot_mask` == 存档值；**成功才删档**，失败保留存档返回非 0。
- [x] **Step 5:** 写 `status` / `selftest`。`status` 输出：slot、subId、运营商名（`dumpsys isub` 的 `displayName`）、`slot_mask`、是否已锁。
- [x] **Step 6:** 真机验证（必须跑）。实测存档是 **54151**（不是下面写的 840583：该机 slot 1 的 NR 早已关闭）：
  ```sh
  adb shell 'su -c "sh /data/adb/modules/asim/scripts/nocamp.sh lock 1"'
  adb shell 'cmd phone get-allowed-network-types-for-users -s 1'   # 期望 GSM
  adb shell 'cat /data/adb/asim/slot1.mask'                        # 期望 840583
  # 确认没动联通卡、且没有 RIL 报错
  adb logcat -d | Select-String "CommandException"                 # 期望无输出
  adb shell 'su -c "sh /data/adb/modules/asim/scripts/nocamp.sh unlock 1"'
  adb shell 'cmd phone get-allowed-network-types-for-users -s 1'   # 期望含 LTE 且含 NR
  adb shell 'ls /data/adb/asim/'                                   # 期望 slot1.mask 已删除
  ```
- [x] **Step 7:** Commit。

### Task 6: `asimd.sh` 守护 + 模块安装/启动/卸载脚本

**Files:**
- Create: `module/scripts/asimd.sh`、`module/service.sh`、`module/uninstall.sh`、`module/customize.sh`、`module/config/asim.conf`

**Interfaces:**
- Consumes: `nocamp.sh` 的内部函数与接口。
- Produces:
  - `asimd.sh start|stop|status`
  - `/data/adb/asim/state.json`（WebUI 唯一数据源）
  - `/data/adb/asim/asim.conf`

- [x] **Step 1:** 写 `customize.sh`（KSU 安装时执行）：建 `/data/adb/asim`（700）；`asim.conf` 不存在才从 `$MODPATH/config/asim.conf` 复制（**不覆盖用户配置**）；模块脚本 chmod 755。
- [x] **Step 2:** 写 `asim.conf` 默认内容：
  ```
  SLOTS="1"
  ROUTER_API="http://192.168.100.1:8080"
  ROUTER_TOKEN="3f9c1c7a5b2e4d6f8a0b1c2d3e4f5a6b"
  ```
- [x] **Step 3:** 写 `asimd.sh start`：用 `flock` 保证单实例（toybox 有 flock），pid 写 `asimd.pid`；循环每 60s：
  - 对 `$SLOTS` 每槽：若 `slot_mask` != 32768 → 重新施加 GSM-only（**不覆盖已有存档**），记日志；
  - 生成 `state.json`；
  - `stop` 时先对每槽 `unlock`，再退出。
- [x] **Step 4:** `state.json` 结构（手写 JSON，**没有 awk/jq，用 sed+grep 拼**）：
  ```json
  {"updated":1763000000,
   "slots":[{"slot":1,"subId":1,"name":"CTExcel","mask":32768,"orig":840583,
             "locked":true,"voice":"OUT_OF_SERVICE","data":"OUT_OF_SERVICE",
             "iwlan":"HOME"}],
   "relay":{"enabled":true,"flows":2}}
  ```
  - reg 状态来源：`dumpsys telephony.registry | grep "notifyServiceStateForSubscriber: subId=<n> " | tail -1`，取 `mVoiceRegState=…(NAME)` / `mDataRegState=…(NAME)`；
  - `iwlan` 来源：同一行里 `transportType=WLAN registrationState=<NAME>`；
  - `relay` 来源：`curl -s -H "X-ASIM-Token: $ROUTER_TOKEN" $ROUTER_API/status`（`/system/bin/curl` 已确认存在）；取不到就写 `{"enabled":null}`，**不能让 curl 卡住**（加 `--max-time 3`）。
- [x] **Step 5:** 写 `service.sh`：等 `sys.boot_completed` → 再 sleep 20（等 telephony 就绪）→ `asimd.sh start`。
- [x] **Step 6:** 写 `uninstall.sh`：`asimd.sh stop`（内含 unlock）→ 兜底再对 `slot*.mask` 逐个 `unlock` → 删 `/data/adb/asim`。
- [x] **Step 7:** 修 `build.sh`（已改名 `build.ps1`：本机无 bash，PowerShell 不执行 `.sh`）与 `module/module.prop`：去掉 `module/bin/mihomo` 依赖（删掉该二进制，build.sh 不再检查），description 改成「防驻网 + 路由器中继」的实际描述。
- [x] **Step 8:** 真机：`build.ps1` → `adb push` → `ksud module install` → **普通 `adb reboot`**（断电需要人按电源键，未做）→ 断言已过：`GSM`、slot 0 未变、WiFi 下 2 分钟内 `WLAN PS = HOME`。短信未验（需外部发一条）。
  - `cmd phone get-allowed-network-types-for-users -s 1` = `GSM`
  - `slot0` 未被改动
  - 连家庭 WiFi 后 5 分钟内 `WLAN: IWLAN, HOME` 且能收短信
- [x] **Step 9:** `asimd.sh stop` 与模拟卸载 → 断言 mask 恢复 `840583`、`slot1.mask` 已删；Commit。
