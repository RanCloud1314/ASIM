# ASIM 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做一个 KSU 模块：把选中 SIM 卡的系统 VoWiFi 流量按 ePDG 目标 IP 路由进 root mihomo 隧道（英国节点），阻止该卡驻网，不影响其他流量，WebUI 管理。

**Architecture:** 系统 WFC 栈不动；asimd（shell 守护脚本）按 IMSI 推导 ePDG FQDN、解析 IP、维护 `ip rule`（pref 8999）与 mihomo TUN 路由；mihomo 以 root 跑 TUN 只含 ePDG 网段；勾选卡槽时用 `set-allowed-network-types` 阻止驻网。

**Tech Stack:** KernelSU 模块规范、mihomo（静态 arm64）、toybox shell 脚本、KSU WebUI（html + ksu exec）。

**Spec:** `docs/superpowers/specs/2026-11-22-asim-design.md`

## Global Constraints

- 所有持久状态存 `/data/adb/asim/`；模块代码只读。
- 不使用 `disable-physical-subscription`（会断电 UICC，AKA 不可用）。
- ip rule 一律 pref 8999，按 dst 匹配；退出/停用必须全部清理（含 uninstall.sh）。
- 订阅凭据文件权限 `chmod 600`，root only。
- 设备：小米 12S Pro（Android 17，KSU 3.4.2），adb 序列号 994e779c；目标卡 subId=1（CTExcel 234/33），受保护卡 subId=2（联通）。CTExcel 当前处于"启用但飞行模式"状态。
- 测试均为真机 adb 验证：命令 + 期望输出写在步骤里。
- M0（Task 1-3）是 go/no-go：任一不过，停止本计划，升级到 spec 的 SWu 备选路线。

## Review Focus

1. **ePDG IP 轮换后旧 ip rule 残留** → 守护循环必须先删后建（按 pref 8999 枚举删除），Task 5 步骤覆盖。
2. **用户日常代理 App 在线时抢路由** → Task 2 在代理 App 开启状态下验证 WFC 注册。
3. **模块停用/卸载后卡仍被锁在 GSM-only（用户手机变砖一样）** → uninstall.sh + 停用路径必须恢复原 network types，Task 6 覆盖。
4. **mihomo 挂掉但 ip rule 还在 → WFC 流量进黑洞** → asimd 检测 TUN 存活，mihomo 死则清规则，Task 5 覆盖。
5. **联通卡流量被误伤** → 每个真机任务都附带"联通卡 ip 直连检查"（`curl ipinfo.io/country` 期望 CN 直连出口）。

### Task 2: M0-B — 系统 IKE 被截获，WFC 手机端独立注册（go/no-go 核心）

**Files:**
- Create: `m0/rules.sh`（冒烟用 ip rule 添加/删除脚本）

**Interfaces:**
- Consumes: Task 1 的 TUN `asim0`。
- Produces: go/no-go 结论写入 `m0/M0-RESULT.md`。

- [ ] **Step 1:** 手机上解析真实 ePDG IP：`adb shell su -c "ping -c1 epdg.epc.mnc033.mcc234.pub.3gppnetwork.org"`，记下 IP（注意若 DNS 被手机代理 App 污染成 198.18.x，改用 `adb shell su -c "ping -c1 -W2 <FQDN>"` 多试或在 PC 侧 `Resolve-DnsName -Server 1.1.1.1` 拿真实 IP 推回手机）。
- [ ] **Step 2:** mihomo TUN 配置加 `inet4-route-address: [<ePDG_IP>/32]` 重启 mihomo。
- [ ] **Step 3:** 加规则：`adb shell su -c "ip rule add to <ePDG_IP> pref 8999 lookup <asim0表>"`（表号用 mihomo 自建路由表；若 auto-route=false 无表，则 `ip route add default dev asim0 table 8999` + `ip rule add to <IP> pref 8999 table 8999`）。
- [ ] **Step 4:** 确保**用户日常代理 App 开着**；关飞行模式之外什么都不动；触发 WFC 重连（`adb shell cmd phone ims disable -s 1 && adb shell cmd phone ims enable -s 1`）。

### Task 3: M0-C — 蜂窝底座 + 防驻网（go/no-go 第二半）

**Files:**
- Modify: `m0/M0-RESULT.md`

- [ ] **Step 1:** 保持 Task 2 的路由，关闭 WiFi，确认手机走联通蜂窝（`adb shell dumpsys connectivity | grep -i active`）。
- [ ] **Step 2:** 触发 IMS 重连，验证 WFC 注册仍成功（同 Task 2 Step 5 断言）。失败 → 记录（蜂窝 NAT 问题），评估：若 trojan 走 TCP 而 NAT 只断 UDP，属节点问题可换节点重试一次；仍失败 → NO-GO。
- [ ] **Step 3:** 防驻网验证——依次测三种方案（真机执行，可复用做 v1 的模式选择）：
  - **方案 A（GSM-only）**：`cmd phone set-allowed-network-types-for-users -s 1 <GSM_BITMASK>`；
  - **方案 B（bitmask 0 / 空）**：设为 0 看是否被接受；
  - **方案 C（手动选网到国外 PLMN）**：`cmd phone` 无直接选网命令时用设置 App 手动选一个不可用的外国网络（选网失败即无驻网，不依赖制式锁）。
  断言：三种各自验证 voice/data reg 不再 IN_SERVICE、且 WFC 仍注册（SIM 上电 AKA 可用）；记录每种是否成立到 M0-RESULT.md。恢复原值并验证卡能正常驻网。默认采用 A，用户勾选卡若当地仍有 2G 覆盖风险则用 C。
- [ ] **Step 4:** Commit，M0 结论汇总。

### Task 5: asimd 守护与规则收敛

**Files:**
- Create: `module/scripts/asimd.sh`、`module/scripts/rules.sh`

**Interfaces:**
- Consumes: `epdg.sh <slotId>` 的 IP 列表；Task 1 的 mihomo/TUN。
- Produces: `rules.sh sync <ip_list...>`（幂等：清空 pref 8999 全部规则→重建，并更新 mihomo `inet4-route-address` 后 reload）；`asimd.sh`（主循环，状态写 `/data/adb/asim/state.json`）；`asimd.sh stop`（清规则、停 mihomo）。

- [ ] **Step 1:** 写 `rules.sh sync`：先 `ip rule del pref 8999` 循环删到没有，再按 IP 列表重建；同时重写 mihomo tun 路由段并 `kill -HUP`/重启 mihomo 生效。
- [ ] **Step 2:** 写 `asimd.sh` 主循环（默认 300s 一轮）：读配置（勾选槽、节点名）→ `epdg.sh` 取 IP → `rules.sh sync` → TUN 存活检查（`ip link show asim0`），mihomo 死则先清规则、拉起、再 sync；写 `state.json`（时间戳、IP 列表、tun 状态、ims 注册态摘要）。
- [ ] **Step 3:** 真机验证（循环两轮）：手动改 FQDN 解析（临时 hosts 一个假 IP）→ 跑一轮 → `ip rule` 期望只剩新 IP 的规则、旧规则消失；杀掉 mihomo → 30s 内规则被清空且 mihomo 被拉起。
- [ ] **Step 4:** 联通卡无感检查 + Commit。

### Task 6: 防驻网集成与清理保证

**Files:**
- Create: `module/scripts/nocamp.sh`、`module/uninstall.sh`
- Modify: `module/scripts/asimd.sh`

**Interfaces:**
- Produces: `nocamp.sh lock <slotId> <mode>` / `nocamp.sh unlock <slotId>`（mode 为 `gsm` | `zero` | `manualplmn`，M0 实测结果决定默认；读存并恢复 `get-allowed-network-types-for-users` 原值，原值存 `/data/adb/asim/slot<slotId>.mask`）；`uninstall.sh` 调 `nocamp.sh unlock` 所有已存 mask 的槽 + 清 pref 8999 规则。manualplmn 模式注意：该模式下的 unlock 需把网络选择恢复为自动。

- [ ] **Step 1:** 写 `nocamp.sh`：lock=记录原 bitmask 后设为 M0 定下的无网值；unlock=从存档恢复并删档。失败处理：set 命令报错时必须回读当前值确认。
- [ ] **Step 2:** asimd 集成：勾选槽启动时 lock，`asimd.sh stop` 与 uninstall 时 unlock。
- [ ] **Step 3:** 写 `uninstall.sh`：unlock 全部 + 清规则 + 停进程。
- [ ] **Step 4:** 真机验证：lock → 卡不驻网且 WFC 正常（同 Task 3 断言）；stop → mask 恢复、`ip rule` 无 8999 残留；模拟 uninstall（直接跑脚本）→ 同样干净。
- [ ] **Step 5:** Commit。
